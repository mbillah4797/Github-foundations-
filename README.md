# GitHub Foundations (GH-900) — 5-Day Hands-On Bootcamp 🎓

This repository **is the classroom**. Every concept on the GitHub Foundations exam gets learned by *doing it here* — real branches, real pull requests, real issues, real Actions runs — then verified and quizzed in chat with Claude.

**Exam:** GitHub Foundations (Microsoft exam code **GH-900**) · **Target exam day:** Tue Aug 19, 2026

> ⚠️ The exam was **significantly restructured in January 2026** and moved to Microsoft Credentials / Pearson VUE in mid-2025. Many older blog posts and courses describe the retired 75-question PSI exam. This curriculum follows the **current official GH-900 study guide**.

## The exam at a glance

| Fact | Value |
|---|---|
| Time limit | **100 minutes** |
| Passing score | **700 / 1000** (scaled — not a raw 70%) |
| Questions | Not published; typically ~40–60 (Microsoft standard range), may include interactive items |
| Delivery | Pearson VUE — online proctored (OnVUE) or test center |
| Price | Region-based (~$99 US); free vouchers via GitHub Student Developer Pack |
| Retake | 24h wait after 1st fail, 14 days between later attempts |
| Full details | [docs/exam-facts.md](docs/exam-facts.md) |

## How each lesson works

1. **Learn** — Claude explains the concept in chat, briefly (2 minutes max).
2. **Do** — you complete a hands-on *mission* in this repo (terminal or github.com).
3. **Verify** — Claude inspects the repo/GitHub and confirms the outcome actually happened.
4. **Quiz** — a few exam-style questions on what you just did, including the known trap answers.
5. Progress gets checked off in [PROGRESS.md](PROGRESS.md).
