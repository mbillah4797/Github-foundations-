# GH-900 Exam Facts (verified August 2026)

## What changed recently — why old guides mislead

- **July 1, 2025:** GitHub certifications moved from GitHub's own portal + PSI proctoring to **Microsoft Credentials + Pearson VUE**. The exam gained the Microsoft code **GH-900**, duration changed from 120 → **100 minutes**, US price rose from $49 → ~$99, and passing is now Microsoft's **700 scaled score**.
- **January 2026:** The study guide's change log says the exam "changed significantly (e.g., new objectives were added, some were removed … and all were reworded)." New domain names/weights, plus new content: Copilot **agents / Agent Mode / multi-model**, **passkeys**, **SECURITY file**, **EMUs**, org-wide Copilot policy.
- Anything quoting "75 questions / 120 minutes / PSI / $49" is describing the retired exam.

## Format

| | |
|---|---|
| Time | **100 minutes** ("You will have 100 minutes to complete this assessment") |
| Questions | Not officially published. Microsoft's standard: "typically 40–60." Recent takers report ~50–60 scored + unscored pretest items (unmarked — answer everything) |
| Question types | Single-answer MC, multi-select ("choose two/three"), and possibly interactive items (drag-and-drop, hot area, build list). Try them at the sandbox: **GHCertDemo.starttest.com** |
| Passing | **700 or greater** on a 1–1000 scale. Scaled — Microsoft explicitly says it does *not* equal 70% correct |
| Languages | English, Spanish, Portuguese (Brazil), Korean, Japanese |
| Open book? | **No.** The in-exam Microsoft Learn reference access is explicitly NOT available on GitHub exams |
| Breaks | Unscheduled breaks allowed, but the clock keeps running and you cannot return to prior questions |
| Result | Shown immediately as pass/fail |

## Registration (do this on Day 1 — slots and pre-checks take time)

1. Go to the official cert page: <https://learn.microsoft.com/credentials/certifications/github-foundations/> (learn.github.com and the old examregistration.github.com both funnel here).
2. Click **Schedule exam** → "Schedule through Pearson VUE" for exam GH-900.
3. Sign in with a **personal Microsoft account** (not work/school — records tied to an org account are unrecoverable if you leave the org).
4. Complete the certification profile. **First and last name must exactly match your government photo ID** — a mismatch on exam day = missed appointment, no refund.
5. Choose delivery: **online proctored (OnVUE)** or a **Pearson VUE test center**. Pick language.
6. Apply any voucher (GitHub Student Developer Pack includes a free one) and pay (~$99 US, region-based).
7. Book the slot. For OnVUE: run the **system pre-check** on the exact machine you'll use; on exam day check in ~30 min early with your ID. Reschedule/cancel ≥24h ahead or forfeit the fee.

### OnVUE room rules
Private quiet room, completely clear desk, no phone/notes/water, government ID in Roman characters matching your registration name, stable (ideally wired) internet.

## Retake policy (Microsoft standard)

- 24-hour wait after a 1st failed attempt; **14 days** between subsequent attempts; max **5 attempts** in 12 months.
- Every retake is paid full price. Reschedule/cancel <24h before = fee forfeited.

## Validity

~**2 years** (GitHub Learn's API reports `validForDays: 730`). Caveat: the public Microsoft page states no validity period, and Microsoft's renewal page doesn't cover GitHub certs — treat 2 years as the working figure.
